# 采集方案的文献核验与本地实施边界

2026-11-03。两份用户材料属于研究建议，逐项核验后实施，不当成已成立的事实。

## 已核验的一手来源

- [VGGT-Ω 原论文 A.1/A.6](https://arxiv.org/html/2605.15195v1)：训练包含低重叠样本；
  细结构深度标注偏差可产生推理失效。它支持“训练监督偏差”假设，不能证明 LEGO 的
  错误必然来自某一训练样本，也不能保证提高分辨率就能修复。
- [官方 reproduction](https://github.com/facebookresearch/vggt-omega/blob/main/reproduction.md)：
  官方因潜在数据污染风险建议 benchmark 使用 416 reproduce 权重，预处理分辨率 416。
  重训调整了训练规模、帧数调度、初始化和监督阶段，故 416/512 比较不只改变分辨率。
- [DA-VGGT](https://jspark1213.github.io/DA-VGGT/)：处理原版 VGGT 的视角组织/冗余，
  不能直接证明 Omega 的 Register Attention 也有同样程度的干扰。
- [RobustVGGT](https://cvlab-kaist.github.io/RobustVGGT/)：内部特征可用于无关视图过滤；
  无关场景拒绝与同一物体内部、存在偏差的深度观测筛选是两个问题。

未把训练 VLM 的过滤规则当成推理硬阈值；未把监督式训练序列过滤器直接移作整图删除器。
当前 512 权重保留历史可比性，416 对照另列；未下载/未运行时不称为独立 benchmark。

## 修订采集规则

1. 高重叠不是 Omega 所有图对的硬要求。需要可连接的几何关系与互补方向；
   COLMAP/局部优化对共同可见性与视差有各自要求，分别记录。
2. 16/32 张、12°、24–40 张均为 LEGO 当前协议的探索结果或经验起点，
   没有跨物体验证，不是通用最优数值或禁止继续拍摄的阈值。
3. 将纯相机旋转与具有平移的视差区分；方位角跨度不等于有效三角测量角。
4. Crop 改变有效像素尺寸，也可能改变视场/注册与尺度；不能未经校准直接注入 TSDF。
5. 转台加静止背景会混合两种运动。对原有移动相机图替换背景只能作代理实验，
   不可称为已模拟物体转台的完整物理成像与反光变化。

## 本地下一组小矩阵

每次固定输入帧数，使用同一固定 Probe 和 val16 协议，分别记原始深度/相机与融合结果。
先做 16 张、512、bf16 单种子可行性；通过后才扩展 3 seeds 和第二物体。

| 轴 | 对照 | 实施约束 |
|---|---|---|
| 有效视差/覆盖 | 同数量的小基线、互补基线集合 | 记录预测三角测量角、共视与原始 pose/depth；角度覆盖本身不等于信息收益 |
| 结构有效分辨率 | 同视图原图、局部放大/缩小 | 图像变换、K 仿射、共同评估网格匹配；先复用已有 tiling 结果，避免重复已失败的直接 crop 融合 |
| 背景 | 固定图像的原背景、遮蔽背景、固定纹理背景 | 首轮只称背景代理；前景边缘合成会引入新伪影，记录 alpha 边界，不声称反光/转台结论 |
| 成像条件 | 复用 B1/B2/B3 的匹配视点结果 | 模糊/曝光/色调不等于真实照明或镜面反射变化 |

冻结：不使用 test 池构造新的输入组。此前 B4 标记为探索；val16 不进入推理、
输入选择、损失或参数挑选。跨场景扫描 GT 必须配准并限制可见区域，不能拿原始扫描
距离冒充已对齐的模型误差。DTU、实拍 mask、416 权重仍有独立的数据/运行门槛。
