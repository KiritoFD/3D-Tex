# 下一阶段：本地已执行结果与剩余工作

2026-11-03。环境为 RTX 4070 Laptop 8 GB、Windows + WSL `ext4`。
参考用户提供的两份方案，保留 A/B/C 三条路线；不把服务器预算当成本地耗时预测。
本阶段目标仍是几何、法线、孔洞和薄结构共同改善，不以单个 F-score 达标代替验收。

## 关键判断

1. 整图负面贡献真实存在，但分清输入贡献与融合贡献。GT 排名不能直接作为部署选择器。
2. M2 可在本地执行，300 步只需约 30–38 秒、峰值显存 0.14–0.22 GiB；
   此前 OOM 是实现/后端问题，不能据此判断 8 GB 无法做 Mesh 优化。
3. 容差深度先验显著改善距离与召回，但会增加表面碎皱；**暂不替换主线资产**。
4. 预测模式必须有原生 Omega 坐标系的初始化。将 GT 对齐的 Mesh 逆变换后输入，
   仍不能消除它在生成时使用的 GT ROI/掩码/内参。下面的 native 对照重新建模。
5. 固定拓扑无法改变内在拓扑，但能移动已有边界/桥接，改变投影孔隙；不应绝对声称
   “任何孔洞都不可能打开”。这也不能代替真正的拓扑修复。

## C1：直接 Mesh 优化，已实际执行

修复：面法线不能用顶点索引访问；平面 crease 权重应为 1；邻接边去重；
