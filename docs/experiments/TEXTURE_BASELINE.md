## 0. 结论：纹理环节的收益有多大

**一句话：在固定 Mesh 上把纹理做到位（可见性/遮挡 + 多视角融合）可以拿回 2.3–3.8 dB（PSNR_fg 2.4–4.4 dB），但这是"修投影错误"的收益，不是"纹理质量"的收益；再往上走全部卡在几何。**

| 对比（heldout 16 视角，1024 atlas） | 代理 Mesh（140,623 顶点） | VGGT Mesh（202,660 顶点） |
|---|---|---|
| 最近视角硬投影 → 完整纹理管线（weighted） | PSNR_fg 14.30 → 18.67（**+4.37 dB**）；PSNR_full 18.77 → 22.52（+3.75）；SSIM 0.7875 → 0.8514 | 13.20 → 15.65（**+2.45 dB**）；17.38 → 19.71（+2.34）；0.7396 → 0.7732 |
| 其中：可见性/遮挡 + 入射角选视角（naive → best_view） | +3.67 dB（fg） | +1.66 dB（fg） |
| 其中：多视角 cos² 加权融合（best_view → weighted） | +0.71 dB（fg） | +0.79 dB（fg） |
| 纹理 vs 纯顶点色（无纹理） | +0.16 dB（fg），SSIM +0.0045 | +0.36 dB（fg），SSIM +0.0010 |
| 纹理分辨率 1024 → 2048 → 4096 | 22.52 / 22.55 / 22.51（**≤0.04 dB**） | 19.71 / 19.64 / 19.53（**−0.18 dB，变差**） |
| 几何上界 oracle（用该 heldout 视角自身烘焙再渲染） | **24.37** full / 20.82 fg | **21.85** full / 17.50 fg |

三条硬结论：

1. **朴素硬投影确实很糟**（差 2.3–3.8 dB），可见性/遮挡判定是必须的；这部分收益与"纹理"无关，是纠正投影错误。
2. **纹理本身几乎没有额外收益**：相对同可见性逻辑下的顶点色只有 +0.11～+0.23 dB（full），分辨率提高 4 倍也没有变化。说明当前分辨率、融合算法、纹理参数化都不是瓶颈。
3. **瓶颈是几何**：固定 Mesh 的 oracle 上界（每个 heldout 视角用它自己烘焙再渲染，纹理整合误差为零）也只有 24.37 / 21.85 dB，比最好的多视角纹理还高 1.85 / 2.14 dB，但仍远低于 GT；同一套纹理管线换 Mesh 就差 2.81 dB（weighted）/ 2.52 dB（oracle）。几何误差包含轮廓、形状与位姿残差，且不止在轮廓边上——把前景腐蚀 8 px 后，内区 PSNR 仍只有 19.52（代理）/ 16.54（VGGT），轮廓环 16.25 / 12.37。

> 提醒：本场景 800×800 大部分是黑底，`PSNR_full` 被背景抬高，判断纹理收益一律以 `PSNR_fg` / `PSNR_inter` 为准。

## 1. 方法与"简化版"声明

管线（与 MVS-Texturing 对应关系）：

| MVS-Texturing 步骤 | 本实现 | 差异 |
|---|---|---|
| 网格清理 / 分块 | 无（几何冻结，不简化、不删连通块） | 保留全部噪声与小岛屿 |
| UV 展开 | xatlas chart 分割 + 参数化 + packing | 等价 |
| 视角选择（labeling） | 逐 texel 选入射角最优的可见视角（`best_view`）；或全可见视角 cos² 加权（`weighted_mean`） | **未做全局 MRF label 优化**，仅逐 texel 贪心 |
| 可见性 / 遮挡 | 视锥 + 朝向（cos > 0.2）+ 网格 z 缓冲自遮挡（`z - zbuf > 2 voxel + 1% z`） | 等价思路，阈值保守 |
| 接缝处理 | chart 边界 4 px gutter 膨胀 | **未做 seam-aware 局部重参数化 / 全局颜色均衡 / 泊松融合** |
| 融合 | cos² 加权平均 | 简化版；不是泊松 / 多 band |

因此本文结果是**简化版 MVS-Texturing**，明确区别于论文实现；但三种策略共享同一套可见性判定，差异只在视角选择与融合，可直接归因。

三种纹理策略：

- `naive_nearest`：每 texel 取相机中心最近的视角直接采样，**不做朝向/遮挡判定**（朴素基线；`naive_filled_share = 1.0`，即所有 texel 都被填色，包括背面与被遮挡区）。
- `best_view`：入射角最优的单个可见视角。
- `weighted_mean`：所有可见视角按 cos² 加权平均。
- `vertex_color`：同样的可见性逻辑，按顶点融合颜色后用 `dr.interpolate` 渲染（无纹理基线）。

评测：heldout 16 视角渲染 vs GT 渲染，PSNR（full / fg / inter / seen / unseen / inner / ring）、SSIM、silhouette IoU、holes/extra share、每像素可见视角数。`inner` = 前景腐蚀 8 px，`ring` = 前景减去内区。

## 5. 接缝表现

接缝定义：chart 边缘 texel 中，3D 距离 < 1.2 voxel、法线点积 > 0.5、且属于不同 chart 的一对 texel 的 |ΔRGB|（0–1 归一化）。边界 texel 超过 200,000 时按固定种子随机降采样（因此表中 boundary_texels 恒为 200,000）。

| atlas | Mesh | chart 数 | 配对 texel | 边界 texel | mean \|ΔRGB\| | p95 \|ΔRGB\| | 配对 3D 距离（voxel） |
|---|---|---|---|---|---|---|---|
| 1024 | 代理 | 15,299 | 506,142 | 200,000 | 0.0595（≈15/255） | 0.2228（≈57/255） | 0.797 |
| 2048 | 代理 | — | 544,086 | 200,000 | 0.0601 | 0.2314 | 0.762 |
| 4096 | 代理 | — | 555,843 | 200,000 | 0.0607 | 0.2384 | 0.748 |
| 1024 | VGGT | 31,464 | 268,109 | 200,000 | 0.0896（≈23/255） | 0.3581（≈91/255） | 0.826 |
| 2048 | VGGT | — | 286,948 | 200,000 | 0.0915 | 0.3937 | 0.788 |
| 4096 | VGGT | — | 293,428 | 200,000 | 0.0882 | 0.3943 | 0.772 |

- 颜色不连续确实存在：VGGT 的 chart 数是代理的 2.06 倍，边界色差均值高 51%（0.0896 vs 0.0595），与"更多 chart + 更差的几何"一致。
- 但**接缝不是主要误差源**：接缝只发生在边界 texel 上，而整幅渲染的 mean|ΔRGB| 为 0.0218–0.0349；4 px gutter 膨胀 + 双线性采样后，肉眼在 4 个 heldout 渲染对比图中看不到接缝线（见 `renders/`）。
- 接缝处更高的色差主要来自**相邻 chart 由不同视角/不同置信权重融合**，本质仍是可见视角不足（VGGT 有 17.8% texel 被遮挡），而不是融合算子本身。

## 6. 瓶颈归因（证据链）

1. **oracle 上界（最强证据）**：在固定 Mesh 上，把每个 heldout 视角"自己拍自己"烘焙成纹理再渲染（这时纹理整合误差几乎为零，只剩几何别名 + 采样），代理 24.37 / VGGT 21.85。最好的多视角纹理 22.52 / 19.71 与之相差 1.85 / 2.14 dB，说明**多视角整合仍有 1.9–2.1 dB 可挖，但挖完之后仍停在 24 / 22 dB**，天花板由几何决定。
2. **换 Mesh 的差距**：同一管线、同一参数、同一评测，代理 vs VGGT：weighted +2.81 dB、oracle +2.52 dB、顶点色 +2.93 dB。纹理完全一致，差的是几何 → 几何是主导变量。
3. **内区也差，不只是轮廓**：腐蚀 8 px 后 `psnr_inner` 代理 19.52 / VGGT 16.54，`psnr_ring` 16.25 / 12.37。轮廓环更差（差 3.3 / 4.2 dB），但内区绝对值同样低，说明是**覆盖整个表面的几何/位姿残差**（VGGT Mesh 在 GT 相机下的轮廓、朝向与 GT 渲染有明显偏差，见 `renders/vggt_atlas1024_val_r_0.png`）。
4. **分辨率无关**：1024→4096 变化 ≤0.04 dB（VGGT 甚至略降），而 1024 的 texel 密度已是像素的 2.6–2.9 倍 → 纹理分辨率不是瓶颈。
5. **纹理 vs 顶点色几乎相等**：+0.11～+0.23 dB → 在这个几何精度下，纹理参数化/接缝/滤波都不是瓶颈。
6. **自遮挡证据**：VGGT Mesh 20.76% 的 texel 没有任何可见视角（17.84% 被遮挡），这些区域只能靠膨胀补色；代理 Mesh 是 6.04%。这类误差不可能靠更好的纹理算法消除，只能靠几何/视角覆盖。

由此，"纹理算法不够好"只解释 1.9–2.1 dB（可继续做全局 label 优化、泊松融合、颜色均衡），**其余 4–6 dB 以上属于几何与位姿**。对当前主线（几何重建）的启示：优先修轮廓与自遮挡，不要指望靠纹理后处理把 PSNR 拉上去。
