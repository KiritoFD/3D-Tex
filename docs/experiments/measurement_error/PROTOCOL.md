# 数据与指标契约

## 物理尺度及基准

用户选择以标准凸点间距 8 mm 标定。工具从源模型的 2×4、4×6、1×8 积木顶盖提取凸点，
检查中心数量和多块积木的最近邻间距。当前 28 块、256 点得到源间距 0.0635763983，
最大相对不一致约 5.53e-7。该比例定义了合成物体的尺寸，不是对某件实物的计量认证。

源资产 SHA、24 个训练视角索引保存在 `master/protocol.json`，求值网格缓存固定不变。
仅使用训练池，不读取 val/test 图像选输入。全局坐标绝对值大于 5 的远处发光平面不参与
物体尺寸或全表面面积采样；这是当前 Lego 场景的明确处理，不是任意场景的通用过滤器。

深度基准采用 CUDA Warp BVH 第一交点，输出相机 z-depth，OpenCV 整数像素中心坐标中
`cx=cy=(W-1)/2`。每种固定网格有 3072 条独立 Blender BVH 检查射线；超过 0.002 mm
最大差异或出现前景支持不一致即报错。普通光栅深度在微小遮挡边缘可能选择错误表面，
因此不用于制造微小噪声基准。GPU 实现参考 [NVIDIA Warp 几何查询文档](https://nvidia.github.io/warp/latest/user_guide/runtime.html)。

RGB GPU 渲染先冻结到同一份源求值网格，并逐顶点/逐三角形核对缓存；保留材质。
Cycles OptiX 只启用 GPU，固定渲染种子和 samples，关闭自适应采样及降噪。
此机器的 OptiX 降噪初始化失败，工具不回退到 CPU 降噪。

## 外部观测误差

`iid` 在每个有效像素生成独立高斯误差；`view_bias` 为每张深度图生成一个共享高斯偏差。
两者均对所有有效观测按目标 RMS 归一化，然后从毫米换到源单位并保存 float32 深度。
因此配置值首先是 **RMS**，不把有限样本的实际 RMS 默认为理论标准差；manifest 记录实际
RMS 和平均有符号偏差。背景、视角、有效采样位置和采样数量不随误差改变。
同一个 seed 在不同档位使用成对噪声场，便于比较。

VGGT 输入 RGB 及输出在此分支固定。初始化融合使用预测相机/深度和输入 alpha 标注；
随后以已知模拟 rig 的相机注册到源坐标，优化使用模拟扫描深度。这是**理想标定/注册条件下
的诊断实验**，不能冒充无需真实标定的部署验证。GT 源几何只用于合成观测与评测。
σ=0 是无噪声扫描对照，`no_external` 是不加扫描约束的优化对照，`initial` 为不优化对照。

固定拓扑、低维形变、正则、先验与分辨率本身都会形成误差下限；噪声不敏感不意味着设备
精度不重要，也可能是优化没有有效吸收扫描约束。现有 RGB 与公开源模型并非完全相同的
渲染版本，该共同差异也限制绝对精度解释。主流程分别固定 256 约束网格、512 评测网格，
本工具当前不做分辨率消融。

新增 M2 选项为 `--external-depth`、`--lambda-external`、`--pixel-center-offset` 和
`--perspective-projection`。新工具使用 +0.5 光栅像素中心修正及标准透视 z 投影；旧命令
默认行为保留。新工具结果不能直接与历史旧投影 M2 数值混为同一实验。

## RGB→VGGT 误差

`object_warp` 生成平滑二维位移场。在每个前景像素，用局部 GT z 和焦距建立
`du = fx * dx_mm / (z_source * mm_per_source_unit)`，并保持二维物面位移 RMS 为配置值。
RGB 在白背景合成后做反向重采样，输入 mask 用同一位移场变换。相机和 GT 物体不变。
这是图像平面定位误差代理：深度断层、遮挡及重采样意味着它不等同于真实三维表面形变。

`camera_jitter` 对相机中心施加三维平移，保持朝向不变，再按全部相机的平移长度 RMS
归一到指定毫米值。RGB 使用实际位置 GPU 重渲染；GT 深度和相机也使用实际位置。
这测试采集位置变化/不稳定对 VGGT 的影响，不把实际位置变化伪装成已知外参标注错误。
两种模式各自保留零误差基线，不能以两套 RGB 来源的绝对分数差直接比较模式优劣。

每档每 seed 都重新运行 VGGT，固定 checkpoint、512 网络输入、BF16 aggregator 与 FP32 heads。
分别输出原始预测的 Depth MAE/RMSE（mm）、AbsRel、法线角、相对旋转误差、相机中心 RMSE
及有效深度覆盖率。Sim3 只用于评价/导出源坐标 Mesh，使用该案例实际 24 相机中心拟合。
输入 SHA、seed、推理尺寸/精度不匹配会拒绝缓存。毫米深度噪声没有被直接喂入 RGB 网络。

## 最终几何表格

- Chamfer L1：两个方向平均欧氏点到**三角形**距离的均值，不是平方距离。
- full：预测 Mesh 面积采样→源 Mesh，与全源面积采样→预测 Mesh；全源含未观察表面。
- observed：反向距离改用固定名义 24 视角的可观察源深度采样；与 full 分列。
- F/P/R：由保存的距离数组，按配置中的毫米阈值重新计算；observed F 另列。
- 法线：预测面积样本面法线与最近源面法线的无符号夹角，单位度。
- Hole fill：固定评测视角中，真实内部孔洞被预测三角形第一交点填上的像素比例。
- thin proxy：GT 512 网格中，局部半径≤2像素的中轴线，测预测深度是否在阈值内；
  这是细窄投影代理，不是逐语义标注的 studs/spokes/rods 保留率。

采样点数/种子固定；默认 50k。CUDA 最近点查询先给距离上界，再枚举上界内所有 AABB 候选，
用 float64 三角形距离细化，避免默认查询在极小三角形上的精度损失。
源表面到自身的 p99.9 距离必须小于 0.002 mm，并记录数值底噪。
改变采样数需要重评测；改变 F-score 阈值只需要重新导表。

`results.csv` 是逐 seed 原始表，`grouped.csv` 是完成项均值/标准差及实际 N，未完成项为
pending/空值。相对无噪声指标按同模式、同 seed 配对；不存在基线则留空。
**当前工具不计算“最大可接受误差”，也不自动推荐设备。**
