## 0. 判定：结论是否仍成立

上一轮结论：

- **P1（纹理收益）**：纹理相对同可见性逻辑下的顶点色只有 +0.16 dB（代理 Mesh）/ +0.36 dB（VGGT）。
- **P2（分辨率）**：1024 atlas 已过采样，1024→2048→4096 变化 ≤0.04 dB。

| 组 | 内容 | 像素级 HF 能量（mean \|Laplacian\|） | P1 | P2 |
|---|---|---|---|---|
| A 低纹理（Lego 现状，上一轮） | Lego 渲染 | 0.0684（像素 3.56 mm） | **成立**：+0.16 dB | **成立**：18.67 / 18.70 / 18.65（≤0.05 dB） |
| B 真实扫描（ETH3D relief） | 真实 DSLR 照片 + 激光扫描 Mesh | 0.0161（像素 1.73 mm） | **成立**：+0.065 / +0.050 / +0.021 dB | **成立**：21.300 / 21.285 / 21.256（Δ≤0.044 dB） |
| C 受控高频（合成） | 程序化 value noise，λ=400→40 mm | 0.0247 → 0.2286 | **不成立**：+7.05 → +1.79 dB | **不成立**：2048 在 λ≤80 mm 才有 +0.20~+0.37 dB；λ≥160 mm 反而 −0.29~−2.87 dB |

一句话判定：**"纹理≈顶点色、1024 已过采样"只在"内容带限 + 几何/位姿残差远大于纹素"时成立。真实数据上两条仍成立，但成立原因是这个真实样本本身不高频、且网格边长远大于纹素；一旦内容真的高频（且几何误差为零），两条都失效。**

## 2. 分辨率口径修正：上一轮"1024 已过采样"的推导量纲不成立

上一轮用"覆盖 texel 数（569,915）是单视角前景像素（196,600）的 2.6–2.9 倍"论证过采样。这两个量不是同一尺度：前者覆盖整个表面，后者只是一个视角的可见像素。正确口径是**纹素间距 vs 像素足迹**：

| 组 | Mesh 面积 | 1024 纹素 | 2048 | 4096 | 平均深度 / fx = 像素足迹 | 1024 纹素/像素 | 2048 | 4096 |
|---|---|---|---|---|---|---|---|---|
| Lego / 合成 | 11.43 m² | 4.47 mm | 2.24 mm | 1.12 mm | 3.96 m / 1111 = **3.56 mm** | 1.26× | 0.63× | 0.31× |
| 真实扫描 | 26.53 m² | 6.61 mm | 3.30 mm | 1.65 mm | 2.95 m / 1707 = **1.73 mm** | 3.82× | 1.91× | 0.95× |

结论：

- Lego 的 1024 纹素（4.47 mm）其实比像素足迹（3.56 mm）**略粗**，不是过采样；2048 才是轻度超采样。
- 真实扫描组 1024 纹素是像素的 3.8 倍，2048 是 1.9 倍，4096 才接近 1:1，**并不存在"1024 已过采样"**。
- 但实测 1024/2048/4096 仍然平坦（Δ≤0.044 dB）——原因是该样本的内容带限（照片 \|Laplacian\| 0.0161，低于 Lego 的 0.0684）与几何残差（Poisson 网格平均边长 17.0 mm，是 1024 纹素的 2.6 倍），而不是"分辨率够了"。

### 频率阈值（合成组给出的定量边界）

- 1024 纹素 4.47 mm，按 Nyquist 能还原 λ ≥ 8.9 mm；2048（2.24 mm）可还原 λ ≥ 4.5 mm。
- 实测 2048 的收益出现在 **λ ≤ 80 mm**（+0.37 dB；SSIM +0.029），与"1.8× 1024 纹素"一致；λ=40 mm 时 2048 仍只有 +0.20 dB（纹素 2.24 mm 对 λ/2 = 2 mm，刚好不足），**要真正解析 4 mm 级图案需要 ≥4096（1.12 mm）或至少 3072（1.49 mm）**。
- 低频段 2048 反而更差（−2.87 dB）且 seam 从 0.0176 升到 0.0291。`filled_share_of_covered` 两档相同（0.9394），因此不是内容分辨率问题，更像是固定 4 px gutter 在高分辨率下覆盖的世界距离减半、留下未填充/错色 texel。此现象本轮未进一步归因，保留为已知问题。
- 该阈值是**内容频率驱动的**，不是"atlas 越大越好"：只有 λ 进入 2× 纹素附近，加大 atlas 才有正收益。

## 3. 样本来源与许可

### 3.1 仓库内检索结果

检索 `data/scenes/`、`outputs/`、既有场景与文档：**没有现成的"含 UV 的真实高频贴图资产"**。可用的真实资产只有 ETH3D 照片 + 激光扫描（无 UV 纹理 GT）；Lego 是渲染图，纹理复杂度低。

### 3.2 真实扫描组：ETH3D `relief`（均为真实照片 + GT 位姿）

- 数据源：`data/scenes/eth3d_relief/`，25 train / 6 heldout DSLR（原始 6212×4141，本实验 0.5 缩放为 3106×2071）、GT COLMAP 位姿、`scan1.ply`（18,438,117 点激光扫描）。
- 官方来源：<https://www.eth3d.net/datasets>；仓库记录见 [DATASETS.md](../DATASETS.md)。
- 许可：官网标注 **CC BY-NC-SA 4.0（仅非商业研究）**；仓库未附许可全文，报告与再分发须保留出处与署名。
- 使用边界：ETH3D manifest 明确禁止把 GT 标定 / 扫描作为 VGGT 或 Gaussian 训练的输入。本实验把 GT 位姿与激光扫描**仅作为固定几何的评测基准**，不参与任何训练或拟合。
- 本组 Mesh 由 `scan1.ply` ROI 裁剪 + Poisson(depth=10) 重建（4 mm voxel，简化到 250k 面，面积 26.53 m²，平均边长 17.0 mm）。

### 3.3 受控高频组：程序化合成（不是扫描结果）

- 由 [synth_hfreq_scene.py](../../scripts/experiments/synth_hfreq_scene.py) 生成：3D value noise（单倍频程），世界波长 λ ∈ {400, 320, 160, 80, 40} mm，70% 高频幅度 + 0.4 m 低频底色；同一代理 Mesh + 同一 GT 相机用 nvdiffrast 渲染 train/heldout，几何误差为零。
- **声明**：该样本只用于验证"高频内容下的算法行为"，不代表真实文物、真实绘画或复杂 PBR 材质，也不是任何真实扫描结果。

### 3.4 若需要真正的高频真实资产，两条可执行路径

1. **获取公开扫描数据**：Smithsonian Open Access（CC0）、Sketchfab CC 授权扫描件、或自采文物的 photogrammetry（含 UV 展开）；这类资产才有绘画/浮雕/磨损细节，但需注意授权与 UV 质量。
2. **受控合成**（本轮已完成）：在现有几何上程序化叠加可控频率图案。它只能隔离"内容频率"这一变量，不能替代真实材质。

本轮的真实扫描组内容实际偏平滑（像素级 \|Laplacian\| 0.0161），**因此"真实高频内容下结论是否成立"仍未被真实数据直接证明**，只被合成样本证伪。

## 4. 收紧后的推论

1. **位姿误差不能解释 Mesh 间差异。** 上一轮（含本轮真实组）全部使用 GT 相机位姿。代理 vs VGGT 的差异（weighted +2.81 dB、oracle +2.52 dB、顶点色 +2.93 dB）只能归因于固定 Mesh 的几何本身，不能归因于位姿误差。
2. **oracle 不是严格的几何上界，只是该 Mesh / UV / 渲染管线下的逐视角参考。** 其实现是"每个 heldout 视角只用自己烘焙 + best_view + 4 px gutter"，`cos>0.2` 或自遮挡判定失败的 texel 仍会被光栅化，却只能用邻居补色。合成组证据（oracle 全部低于 weighted）：
   - λ=400：21.24（1024）/ 19.90（2048）vs weighted 31.21 / 28.33
   - λ=160：18.41 / 18.02 vs 25.29 / 25.00
   - λ=40：16.94 / 16.70 vs 18.99 / 19.19
   因此上一轮"oracle 上界 → 天花板由几何决定"的措辞必须降级为"该管线内的逐视角参考"。
3. **Lego 的低纹理复杂度不能代表真实文物、高频绘画或复杂 PBR。** 合成组已给出反例：同样的 Mesh、UV、相机与融合算法，仅把内容换成 λ≤160 mm 的图案，纹理相对顶点色的收益从 +0.16 dB 升到 +3.82~+7.05 dB；2048 也开始出现正收益。
4. **（新增）真实扫描组仍成立的原因不是"高频"，而是"带限 + 几何粗糙"。** 照片在 1.73 mm 像素上 \|Laplacian\| 仅 0.0161（比 Lego 的 0.0684 低），Poisson 网格平均边长 17 mm 是 1024 纹素的 2.6 倍，所以纹理既没有可保留的高频，也承载不了细节。**不能拿这一组去支撑"1024 过采样"的普遍结论。**
5. **（新增）本轮没有取得"真实高频"资产。** 真实组的图像内容偏平滑，合成组是程序化图案；两者都不能代表真实文物材质。若要把结论外推到真实高频文物，必须先补一组带 UV 的高频扫描资产。
