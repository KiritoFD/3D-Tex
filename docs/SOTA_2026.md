# 2025–2026 多视图 Mesh / UV 方法选型（截至 2026-11-01）

**“SOTA”不应单选**：几何 DTU CD、网格编辑性/UV、未知区域纹理生成 FID、真实材质 PBR 是不同赛道。下面优先用**论文正文和作者发布仓库**核对数据，未验证的硬件/模型结果不作承诺。

## 1. 先做决定

- **首选可运行、纯非 Gaussian baseline：** `VGGT-Ω -> 深度/相机 -> TSDF Mesh -> xatlas -> 多视图烘焙`；这是工程组合**不是已发表 SOTA 模型**，可用于判断后续是否真需要优化。
- **几何精度强候选：GeoSVR（NeurIPS 2025 Spotlight）**，优化 sparse voxels 而非 Gaussian；DTU 平均 CD **0.47**，但 mesh 需要 TSDF 提取、UV 需要额外处理。
- **最终 Mesh/UV 的优先算法候选：ExMesh（CVPR 2026）**，显式顶点、拓扑 split/merge 和 UV 纹理协同；论文 CD **0.58**、约 **13–15 min**、约 **196K faces**、显存 **4.5GB**。**实现默认 PGSR 5k 初始化**，不是即插即用的 VGGT→TSDF；替换需研究验证。
- **最新资产导向：ExMesh++（arXiv 2026-08）**，在 ExMesh 风格的 mesh+UV carrier 上做 PBR/环境光分解；预印本，公开可用代码与复现还需确认。
- **其它已找到的 MiLo、OMeGa、2D-SuGaR 依赖 Gaussian**，只记录文献，不引入无 Gaussian 默认路线。
- **MeshSplatting（CVPR 2026）**属于可优化不透明三角网格，非 3DGS，但其主要 metric 是新视角 PSNR，**不是 UV 纹理质量**。

| **[DMesh++](https://openaccess.thecvf.com/content/ICCV2025/html/Son_DMesh_An_Efficient_Differentiable_Mesh_for_Complex_Shapes_ICCV_2025_paper.html)**，Sanghyun Son、Matheus Gadelha 等；UMD + Adobe Research | **ICCV 2025** | topology-differentiable mesh/points，非 Gaussian | 论文将关键操作复杂度 **O(N)→O(log N)**；这不是 CD 精度排名 | [project/code](https://sonsang.github.io/dmesh2-project/)，研究复杂拓扑/薄结构可借鉴 |
| **[MILo](https://anttwo.github.io/milo/)**，Antoine Guédon 等，École Polytechnique/Inria 等 | **SIGGRAPH Asia 2025 / ACM TOG** | **Gaussian + differentiable mesh extraction** | 2D-SuGaR/ExMesh 等论文的对照并非相同 UV 质量 benchmark | 依赖 Gaussian，只保留文献 |

**比较方法论**：GeoSVR 0.47 与 ExMesh 0.58 是 ExMesh 的 DTU 15 scans 表格可横向阅读；但具体初始化、mono priors、GT 掩码、对齐/采样脚本不同，不能只靠这两个数预测 Ω 初始化的新实验。MeshSplatting 的 +0.69dB 来自 **Mip-NeRF360 novel-view synthesis**，不是几何/纹理正确性的证据。ExMesh++、ExMesh 的部分表格内容亦存在模型/版本差别，不能把预印本当完整可复现正式论文。

| **[Lafite](https://openaccess.thecvf.com/content/CVPR2026/html/Chen_Lafite_A_Generative_Latent_Field_for_3D_Native_Texturing_CVPR_2026_paper.html)**，Chia-Hao Chen、Yuan-Chen Guo、Song-Hai Zhang 等 | **CVPR 2026** | sparse 3D latent color field VAE + rectified flow | 作者报告**VAE 纹理重建**比对照方法高 >10dB PSNR；不是同 UV 展开算法的提升 |
| **[Intrinsic Image Fusion](https://openaccess.thecvf.com/content/CVPR2026/html/Kocsis_Intrinsic_Image_Fusion_for_Multi-View_3D_Material_Reconstruction_CVPR_2026_paper.html)**，Peter Kocsis、Lukas Höllein、Matthias Nießner；TUM | **CVPR 2026** | 从照片恢复材质与光照，优化可重光照参数 | 面向逆渲染而非纹理 hallucination，更适合实拍资产 |
| **[TEXTRIX](https://openaccess.thecvf.com/content/CVPR2026/html/Zeng_TEXTRIX_Latent_Attribute_Grid_for_Native_Texture_Generation_and_Beyond_CVPR_2026_paper.html)**，Yifei Zeng、Yajie Bao 等 | **CVPR 2026** | 稀疏 3D attribute grid DiT，非纯 UV | 原生纹理与语义统一，属于重新训练大型 3D 模型而非简单下游替换 |

**目标区别**：真实纹理恢复（可观测表面应忠实照片）优先做 visibility-aware 纹理融合/光度优化；生成模型只处理未观测区域及材质解耦。生成 FID 与实测 PSNR/UV seam error 必须分表。

## 4. 关键工况和工程风险

1. **VGGT-Ω 权重许可/访问**：checkpoint 需要 HF 申请；512 in-the-wild checkpoint 与 416 Sep reproduction checkpoint 不等价；默认不下载或推送权重。[官方仓库](https://github.com/facebookresearch/vggt-omega)。
2. **ExMesh 不能直接视为 Gaussian-free 工程**：公开 README 明确推荐 PGSR 5000 steps、TSDF coarse mesh 后训练；新的 Ω TSDF 初始化方案是我们提出的实验。[代码说明](https://github.com/Fan-Treasure/ExMesh)。
3. **GeoSVR 需要其它预训练深度 cue 与 CUDA sparse voxel renderer**；改 Ω depth 必须校准尺度/置信度，不能直接套默认配置。[README](https://github.com/Fictionarry/GeoSVR)。
4. **ExMesh++ 不等于 ExMesh 的 GitHub 代码**，目前仅确认论文/项目页，代码可用性须单独核对；PBR 纹理需要额外反照率/粗糙度/光照监督或物理渲染。
5. **计算资源**：Ω 官方 A100 25 帧 7.80GB（512），ExMesh 原文 DTU 4.5GB、GeoSVR 附录 11.2GB；一张 4090 能合理作为首轮预算，但这种跨方法数字不应作为本仓库实测显存结论。

## 5. 最终选择

- **验收路线 A0**：`VGGT-Ω -> Robust TSDF -> xatlas -> bake`，低开发风险，可定位 geometry vs texture 问题。
- **A1**：`VGGT-Ω -> TSDF -> adapted ExMesh -> UV bake`，主研究方向；尽早确认细结构/拓扑/UV 在替换初始化后是否退化。
- **A2**：`VGGT-Ω -> GeoSVR -> mesh -> xatlas/bake`，几何 upper-quality 对照，可能比 A1 慢且输出需要额外 UV。
- **独立 texture 方向**：`fixed mesh+UV -> observed atlas -> seam-consistent repair / MatLat/MV2UV`。不要把 mesh 优化、PBR 分解、UV 生成和 3D 原生 DiT 同时重训。
